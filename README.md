# Pengram

<img src="branding/pengram_icon.png" width="120" align="right" alt="Pengram icon"/>

Форк официального Telegram для Android со своими ключами API, собственной иконкой/названием
и набором фич в духе AyuGram / exteraGram. Ставится **рядом** с оригинальным Telegram
(`applicationId = org.telegram.messenger.pengram`), ничего не затирает.

Все настройки форка собраны в одном месте: **Настройки → Pengram** — пункт закреплён
самым первым, выше «Аккаунта». Дополнительные входы: «три точки» на главном экране,
поиск по настройкам (пункты Pengram ищутся как родные) и диплинк `tg://settings/pengram`.

Внутри экран разложен по разделам: **Основное · Профиль · Оформление · Кастомизация ·
Чаты и кнопки · Режим призрака · История сообщений · Медиа и скорость · Свобода и Premium**.
Сверху экрана живёт **3D-пингвин** — его можно крутить, тыкать и переодевать (см. ниже).

## Что уже есть

### 👤 Профиль
- **ID пользователя/чата** отдельной строкой под юзернеймом: крупно сам ID, мелкой подписью —
  расположение дата-центра, `DC 5, Singapore, SG`. Стили: не показывать · `ID` ·
  `ID` + дата-центр · рядом с юзернеймом.
- **Копирование ID по тапу** (отключаемо).
- **Формат ID** выбирается крупными строками с живым примером: `скрыть` ·
  `Telegram API` (`1234567890`) · `Bot API` (`-1001234567890`).
- **Дата регистрации аккаунта** — отдельной строкой или иконкой прямо в строке ID
  (календарик · пингвин · часы · без значка, цвет берётся из темы — ничего не «чернеет»).
  По нажатию: «Вы создали свой аккаунт примерно в марте 2021» (+ возраст аккаунта).
  Можно включить **показ текста прямо в строке**, без всплывающего окна.
  Вычисляется интерполяцией по ID, поэтому приблизительная.
- **Скрытие своего номера телефона** локально — в профиле и в шапке настроек вместо номера «Номер скрыт».
- **Живое превью** в настройках: карточка профиля перерисовывается сразу при смене стиля.

### 👻 Режим призрака
Мастер-тумблер + независимые опции:
- всегда оффлайн (не отправляется `updateStatus`);
- не отправлять прочтение сообщений (локально читается, собеседник галочек не видит);
- не отправлять статус «печатает»;
- не отмечать просмотр историй.

Быстрый тумблер режима призрака вынесен в **«три точки» на главном экране** — с галочкой и
всплывающим подтверждением, без захода в настройки.

**Локальное отслеживание** (работает независимо от призрака): Pengram запоминает у себя
даты прочтения ваших сообщений и последние заходы собеседников — даже когда Telegram их прячет.

### 🗃 Неубиваемая история удалённых и изменённых
- Отдельная база `pengram_history.db` в `files/` — **очистка кэша Telegram её не трогает**.
- Удалённые сообщения перехватываются до удаления из кэша, изменённые — сохраняются парой
  «было → стало».
- Опции: сохранять удалённые / изменённые / свои исходящие / в чатах с ботами /
  показывать строку в профиле. Зависимые пункты скрываются, если сохранение выключено.
- **Сохранение медиа удалёнок** в выбранную папку:
  фото → `Pictures/<папка>`, видео → `Movies/<папка>`, файлы → `Download/<папка>`,
  с настраиваемым **шаблоном имени** (`{date}`, `{time}`, `{chat}`, `{id}`, `{dialog}`).
- **Лимит размера папки вложений** — слайдер по ровным ГБ (без лимита · 1 · 2 · 4 · 8 · 16 · 32 · 64):
  при достижении лимита самые старые файлы удаляются автоматически. Показывается занятый объём,
  есть кнопка «удалить все сохранённые вложения».
- Просмотр: фильтр Все / Только удалённые / Только изменённые, старый текст зачёркнут,
  долгий тап — копировать или удалить запись, в шапке — очистка.
- **Просмотр удалёнок как обычного чата**: сообщения идут лентой, с разделителями по датам,
  временем отправки и пометками «удалено» / «изменено» теми значками, которые выбрал пользователь.
  Удалённые — полупрозрачные (отключаемо), тап по метке показывает подробности.
- Статус «удалено/изменено» прилетает **вживую**, перезаходить в чат не нужно.
- Точки входа: Настройки → Pengram, строка в карточке профиля, и **остров Pengram
  в меню «три точки» внутри чата**. В острове намеренно ровно **одна** кнопка —
  «Посмотреть удалёнки» (всё удалённое и изменённое этого чата, с счётчиком).
  Позиция острова настраивается — сверху (сразу после «Уведомлений») или снизу меню.

### 🔓 Без ограничений
- **Скриншоты и запись экрана везде**: секретные чаты, одноразовые медиа, истории,
  просмотрщик фото/видео, экраны оплаты, звонки, пасскод.
- **Не уведомлять о скриншоте** в секретных чатах.
- **Обход запрета пересылки/сохранения** в «закрытых» каналах и чатах (копирование,
  пересылка, сохранение медиа, кнопка копирования кода).
- **Одноразовые медиа не «сгорают»** — просмотр не подтверждается серверу, поэтому
  фото/видео/голосовые «один раз» остаются, их можно пересматривать, пересылать и сохранять.

### 🚫 Реклама
Спонсорские посты не запрашиваются у сервера вообще — ни в каналах, ни где-либо ещё.
Работает без локального премиума, без «дырок» в ленте и лишних запросов.

### ⭐ Локальный Premium
Разблокирует клиентские premium-функции (анимированные эмодзи и статусы, premium-пункты
интерфейса, расширенные лимиты UI). Серверные возможности по-прежнему требуют подписки.

### 🚀 Ускорение сети
Режимы **Как в оригинале · Быстро (2x потоков) · Максимум (4x потоков)**:
- скачивание — большие куски 512 КБ и до 8–16 параллельных запросов на файл (включая стриминг видео);
- отправка — во столько же раз больше параллельных частей и несколько файлов одновременно
  (в оригинале файлы грузятся строго по одному).
На медленных сетях буст автоматически не применяется.

### 🎙 Изменение голоса в голосовых
Эффект накладывается **прямо при записи**, поэтому собеседник слышит изменённый голос.
- Пресеты: Гелий · Ребёнок · Выше (женский) · Ниже (мужской) · Очень низкий · Монстр · Робот.
- «Свой сдвиг» — слайдер от −12 до +12 полутонов.
- Экран с «островком»-превью: живая анимированная волна, частота и амплитуда которой
  зависят от выбранного эффекта, и подпись со сдвигом тона у каждого пресета.
- Реализовано на чистой Java (гранулярный питч-шифтер по PCM), без нативного кода;
  при выключенном эффекте запись не трогается вообще.

### 🧹 Скрытие лишних кнопок
- Меню главного экрана: «Создать группу», «Избранное», «Настройки», переключатель темы.
- Меню чата (ЛС, группы, каналы, боты): Поиск, Перевести, Очистить историю, Обои,
  Добавить на экран, Пожаловаться, Звонок, Автоудаление.

### 🎨 Внешний вид
- Шрифт приложения: Telegram · системный · с засечками · моноширинный.
- Позиция острова Pengram в меню чата.
- Своя иконка-пингвин (адаптивная + монохромная для тем Android 13+) и название **Pengram**.
- Размер шрифта и радиус «пузырей» сообщений — слайдерами, с живым превью переписки.
- Центрирование заголовка, скрытие «хвостика» у пузырей, вечный снег.

### 🐧 Живой 3D-пингвин
Шапка настроек Pengram — настоящий 3D-пингвин, нарисованный своим мини-движком на
OpenGL ES (меши строятся из эллипсоидов, конусов и торов, без моделей и библиотек):
- **жесты**: тап — прыжок, двойной тап — сальто через голову, долгое нажатие — танец
  с маханием крыльями, свайп — раскрутка; дальше он мягко возвращается в исходную позу;
- **скины**: без одежды · Санта · шарф · кепка · очки · корона · наушники · бабочка · шляпа мага —
  переодевается прямо из настроек, с прыжком и приветственным взмахом крыла;
- **десять быстрых тапов** по пингвину открывают отдельный раздел «Пингвин» — там живут
  все скины с описаниями и подсказки по жестам, а выбранный скин надевается мгновенно;
- под пингвином — версия сборки.

### 🔎 ID работает везде
ID перестал быть «просто цифрами в профиле»:
- **глобальный поиск** понимает ID — вводите `1234567890` или `-1001234567890`
  и получаете чат/человека даже без общей переписки и без юзернейма;
- найденный по ID пир предлагает **открыть чат** или **открыть профиль**;
- **поиск внутри чата** по ID автора: «от кого» принимает ID так же, как имя;
- упоминания и выбор получателя тоже матчатся по ID;
- ID копируется тапом, формат (Telegram API / Bot API / скрыть) общий для всего приложения.

### 🧩 Кастомизация
Отдельный раздел с превью «как в настоящем чате»:
- **метки удалённых и изменённых сообщений** — рисованные векторные значки
  (корзина · крестик · глаз · огонь · карандаш · часы · точка) или вообще без значка:
  тогда у изменённых показывается обычное «изменено», как в ванильном Telegram;
- полупрозрачность удалённых сообщений, скрытие подписи «изменено»;
- **своя аватарка** в превью профиля и реальный ID аккаунта в примерах;
- превью не «подсвечивается» и не реагирует на тапы — это картинка, а не кнопка.

### 🎛 Порядок и видимость кнопок
Любые наши пункты можно **перетаскивать и прятать**:
- меню «три точки» на главном экране;
- список разделов в самих **Настройках** (Pengram по умолчанию в самом верху);
- пункты Pengram в **меню чата** — экран собран из «корзин»: «в меню три точки»,
  «в острове Pengram» и «скрытые». Пункт переносится между ними перетаскиванием
  или одним тапом (по кругу), всё с плавной анимацией — так что «Посмотреть удалёнки»
  можно вынести прямо в «три точки», а «В начало» наоборот спрятать в остров;
- кнопки нижней панели вкладок;
- сам раздел Pengram в Настройках — отдельной плашкой над всем остальным (отключается).

### 🎵 Плеер в духе Spotify
Плеер Pengram вместо стандартного — и его вид выбирается картинками, а не галочками
(«Pengram → Плеер → Вид плеера»): «Как в Telegram», «Большая обложка», «Текст песни»,
«Компактный» и «Компактный с текстом». У каждого вида — живая миниатюра, а десять
анимаций текста показаны прямо в сетке: каждая карточка сама проигрывает строчку.
- большая обложка (скруглённая · круг · квадрат), фон — размытая обложка, градиент из её
  цветов, тёмный или цвет темы; акцентный цвет кнопок подбирается из самой обложки;
- **текст песни находится сам**: Pengram спрашивает его у открытой базы LRCLIB по
  исполнителю и названию, показывает «Ищем текст…», а найденное кладёт в локальный кэш,
  чтобы второй раз не искать. Не нашлось — есть кнопка «Попробовать ещё раз» и ручной ввод;
- компактные виды — небольшая карточка внизу экрана, тап мимо неё закрывает плеер;
- **очередь**: кнопка списка в шапке открывает всё, что играет сейчас и дальше, —
  с обложками, длительностью, подсветкой текущего трека и переходом по тапу;
- кнопки переключения треков нарисованы вектором и пружинят при нажатии, а скорость
  показывается честной подписью («1,5×») со списком всех значений по долгому нажатию;
- крупные контролы, перемотка, скорость, повтор и перемешивание — всё на месте;
- **текст песни с побуквенной анимацией**, шестнадцать вариантов: караоке, по буквам,
  волна, подпрыгивание, печатная машинка, пульс, неон, радуга, размытие, перелив, тряска,
  падение, переворот, блик, лупа или вообще без анимации — и все они проигрываются
  прямо в сетке выбора;
- **подсветка «буква в букву»**: если у трека есть пословные метки (enhanced LRC), слова
  загораются ровно по голосу, а не по среднему времени строки;
- текст ищется в нескольких источниках подряд (LRCLIB → textyl → lyrics.ovh), поэтому
  находится даже то, чего нет в одной базе;
- понимает LRC-таймкоды (`[00:12.34] строка`) — тогда это настоящее караоке с тапом
  по строке для перемотки; обычный текст тоже подходит, строки распределятся по треку;
- настраивается размер текста, выравнивание, жирность, тень, приглушение остальных строк,
  скорость анимации и автопрокрутка. Тексты хранятся локально и привязаны к «исполнитель — название».

### 🧱 Конструктор интерфейса

#### Редактор экрана
Самое верхнее в конструкторе — **целый Telegram в миниатюре**: шапка со списком чатов,
сообщения с аватаркой и меткой удалённого, панель кнопок чата, строка ввода и нижние
вкладки. С ним работают пальцем, как с настоящим экраном:

- **касание** — элемент выделяется, внизу всплывает его собственная панель настроек;
- **долгое нажатие и перетаскивание** — элемент берётся в руку, подходящие места
  подсвечиваются пунктиром: аватарку можно положить слева от пузыря, перед именем,
  после имени или справа, а панель кнопок чата — под шапку или к строке ввода;
- **повторное касание** перебирает значения на месте: заголовок в шапке, значок
  удалённого сообщения, видимость любой нижней вкладки;
- **ползунки** в нижней панели меняют скругление пузырей и размер текста — и макет, и
  само приложение перерисовываются в ту же секунду.

Остальные карточки конструктора — живые превью отдельных частей:

- **нижние вкладки** — настоящая панель с «Чатами», «Контактами», «Звонками», «Настройками»
  и «Профилем»: нажал на вкладку — она уехала (или вернулась) с анимацией, главный экран
  перестраивается сразу, без перезапуска;
- **шрифт сообщений** — пара живых пузырей вашим размером и скруглением; нажатие
  примеряет следующий шрифт;
- **список чатов** — строка диалога целиком, нажатие перебирает форму аватарки
  (круг → скругление → квадрат);
- **плеер** — макет экрана музыки, нажатие переключает стиль (оригинальный Telegram,
  караоке, компактный, мини-текст, полный);
- **текст песни** — витрина анимации, нажатие листает все 16 вариантов.

#### Эффекты удаления
Сообщение не просто пропадает, а красиво уходит: **пыль**, **сгорание** с живой линией огня,
**осколки**, **схлопывание**, **растворение**, **улетает**, **в точку**, **пиксели** — и «выключено».
Отдельный экран показывает настоящий пузырь сообщения: нажал на эффект — он тут же проигрался
на нём, и сразу стал текущим. Можно отключить эффект для чужих удалений.

#### Обход блокировок — одна галочка
Никаких списков, режимов и настроек: в разделе «Свобода» один переключатель.
Включили — и дальше приложение само следит за связью. Как только Telegram перестаёт
подключаться, Pengram по очереди пробует три способа, от самого быстрого к самому пробивному:

1. **Разрыв пакета** — соединение остаётся прямым, но первые байты разрезаются на несколько
   отдельных пакетов с микропаузой. Фильтр собирает поток по первому пакету, подписи Telegram
   в нём не находит и пропускает. Посредников в цепочке нет, скорость обычная.
2. **Туннель через сайт** — внутри приложения поднимается маленький SOCKS5-вход на 127.0.0.1,
   сетевое ядро отправляется ходить через него, а наружу поток уходит обычным HTTPS-подключением
   к сайту на Cloudflare: TLS, затем WebSocket, внутри — поток к серверам Telegram (VLESS).
   Снаружи это неотличимо от открытия веб-страницы, поэтому способ проходит даже там,
   где разрешён только белый список адресов.
3. **Вход MTProto** — классический запасной вариант.

Победивший способ запоминается и в следующий раз включается сразу, без паузы. Когда блокировка
отпускает, приложение само возвращается на прямое соединение, потому что оно быстрее.
Список входов собирается сам из открытых каталогов (зеркала на том же Cloudflare идут первыми),
каждый проверяется настоящим подключением до сервера Telegram, хранятся два десятка лучших.
Можно вставить и свою ссылку `vless://` или `tg://proxy` — ваш вход всегда пробуется первым.
Прокси, настроенный вами вручную, не трогается. Через туннель идут сообщения, медиа и каналы;
звонки используют отдельный канал и пока не покрыты.

#### Тексты песен: быстро и точно
Всё делается само: режим «Полностью автоматически» включён изначально — источник, тайминги
и предзагрузка не требуют ни одного касания. Если вы когда-то подвинули текст руками,
приложение это запоминает и применяет поправку к следующим песням само.
Текст ищется сразу в нескольких источниках параллельно (LRCLIB, Musixmatch, Genius и
встроенный в файл тег), поэтому находится гораздо чаще и приходит почти мгновенно —
для следующих треков списка он и обложка подгружаются заранее. Если строки всё же
спешат или отстают, в плеере есть кнопки **−0,5 c** и **+0,5 c**: они запоминают сдвиг
именно для этой песни. В настройках есть выбор источника, общий сдвиг и растягивание
текста по длине трека.

Ниже, в «Подробных редакторах», — то же самое с перетаскиванием пальцем: меню чата,
кнопки в чате, экран настроек, список чатов и плеер.

### 🎤 Строка песни в шапке чата
Мини-плеер вверху чата показывает не «исполнитель — название», а **ту строку, которая
звучит прямо сейчас**, со словами, загорающимися по ходу пения. Названию трека строка
уступает место обратно, как только песня закончилась или текст не нашёлся.
В «Плеере» это выключается одним тумблером, а анимацию для шапки можно выбрать
отдельно от большого плеера — «как в плеере» или любой из 16 вариантов, плюс размер букв.

### 🎵 Треки в этом чате
Кнопка списка в плеере открывает не абстрактную «очередь», а все треки этого чата:
аккуратные карточки, у играющего — живой эквалайзер, нажатие сразу запускает трек.

### ✍️ Оформление не слетает
Жирный, курсив и остальное продолжаются при наборе и **не сбрасываются**, когда заходишь
исправить уже отправленное сообщение. Отключается одним тумблером в «Чатах».

### ✉️ Сообщения и выделение
- **лимит выделения** 100 · 200 · 300 · 500 · 1000 · 1500 · 2000 · 3000 сообщений вместо жёстких 100:
  пересылка и удаление сами режутся на пачки по 100 и уходят с паузой, чтобы не ловить
  флуд-вейт и не подвешивать интерфейс;
- **пересылка удалёнок и одноразок**: такие сообщения сервер переслать не даёт, поэтому
  Pengram отправляет копию из кэша — с медиа и подписью, а не пустую заглушку;
- **аватарка автора** — пять мест на выбор: слева, справа, до ника, после ника или спрятать.
  Выбирается не списком, а наглядно («Pengram → Чаты → Вид сообщений»): сверху живое превью
  настоящих сообщений, снизу — ячейки с эскизами, и аватарку можно просто **перетащить**
  пальцем туда, где ей место (или тапнуть по ячейке). Результат виден сразу.

### 🧼 Фильтр Zalgo
Убирает «ломающие» символы (комбинируемые диакритики) **везде, а не только в тексте сообщений**:
имена и фамилии, названия чатов и каналов, подписи к медиа, превью в списке диалогов,
результаты поиска. Переключается одним тумблером и применяется к уже загруженному кэшу сразу.

## Сборка

### GitHub Actions (рекомендуется)
Вкладка **Actions → Build Pengram (Android arm64-v8a) → Run workflow**.
Выбираются тип сборки (`standalone` / `debug`) и ABI (по умолчанию `arm64-v8a`).
Готовый APK лежит в артефактах запуска. Сборка также стартует при пуше тега `build-*`.

Workflow сам ставит JDK 17, Android SDK, NDK 27.2.12479018 и CMake 3.22.1. Для скорости
подключены **ccache** (кэш компилятора C/C++ между запусками), **Gradle build cache**,
кэш `.cxx`/`~/.gradle` с обновляемыми ключами и параллельные воркеры — повторные сборки
заметно быстрее первой.

Подпись: по умолчанию ключ из репозитория. Свой ключ — через секреты
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

### Локально
```bash
./scripts/build-arm64.sh standalone   # или debug
# APK: TMessagesProj_AppStandalone/build/outputs/apk/...
```
Нужны JDK 17, Android SDK, NDK `27.2.12479018`, CMake `3.22.1` и `git submodule update --init --recursive`.
