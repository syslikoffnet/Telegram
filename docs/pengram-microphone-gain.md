# Microphone boost and overdrive presets (voice messages and voice chats)

Settings → Pengram → Media → Voice studio → Microphone boost. Select Original (0 dB), Clear (+9 dB), Loud (+18 dB), Battle (+30 dB), Custom (initially 0 dB), or Overload (+60 dB and 100% overdrive). The five editable slots each store their **own 0–60 dB boost and 0–100% overdrive**. Select a slot and move either slider to edit it; the Set maximum button restores Overload to +60 dB / 100% even if it was edited earlier; changing a slider while Original is selected switches to Custom. Existing saved values in the other slots are not overwritten on upgrade. Preset selection and per-slot controls persist and are included in Pengram settings backups.

## Separate “Trolling · clear speech” voice mode

Select the dedicated **Trolling · clear speech** tile in Voice studio (it is next to Off). This mode is optimized for legible, consistently loud microphone speech rather than intentional distortion: a 100 Hz rumble cut, light articulation boost, conservative noise expansion, adaptive speech-level gain (0.65–20×), and a final PCM peak limiter. It runs with no pitch shift, echo, neural model, or extra lookahead; level and filter coefficients adapt to the actual 8–96 kHz input rate. The same mode applies to opted-in calls/group voice chats and voice notes. Calls remain off until explicitly enabled using the source switch. **This mode intentionally ignores the separate manual boost and Overload distortion preset**, including if it was selected previously; use another mode for deliberately distorted audio.

The boost is applied to outgoing PCM16 before encoding, with the same selected preset for voice messages and calls/group voice chats. Calls are explicitly opt-in via the **Calls and group voice chats** switch (off by default). Video messages are independently opt-in. Boost/overdrive also work with voice timbre effects Off or effect mix at 0%. With effects enabled they follow the effect and precede the peak limiter. Original with effect Off bypasses the WebRTC JNI buffer entirely.

Overdrive is intentional nonlinear saturation: samples below its adjustable knee remain unchanged; those above it become progressively more compressed. Even at 60 dB of pre-limiter gain, the final output is capped to 30,000/32,768 to avoid PCM16 wraparound. Digital gain and distortion **cannot** make a remote speaker exceed its own hardware volume limit; extremely loud playback may damage hearing. Device AGC, mic sensitivity, prior clipping, Opus, and network processing can change the audible result. High gain also boosts room noise. Start with moderate settings, especially when testing with headphones or speakers nearby.

Portable effect profile JSON accepts optional `gainDb` (0–60) and `overdrive` (0–100) fields. Old profiles without these keys import as 0/0, select the Custom boost slot, and do not enable microphone processing in calls. `drive` (0–6) remains the separate legacy studio filter setting; do not confuse it with `overdrive`. These are signal-processing presets, not neural voice models.
