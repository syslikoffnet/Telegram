# Отправка текста: откат на официальный код мастера

## Итог

Решение пользователя (2026-10-23, после24 часов и трёх отклонённых
устройством сборок): **`TextMessageEnterTransition.java` побайтово равен
мастер-сборке** (run397 — «текст отправляется нормально» по подтверждению
пользователя). Сессионные схемы откатаны полностью:

* обёртка `drawFieldCopy` и «вторая копия по требованию» — удалены;
* замена `saveLayerAlpha` на paint-альфу в кроссфейде поля (run401) —
  удалена, официальный слой на месте;
* жизненный цикл `finishTransition()` / поколения / `onAnimationCancel` /
  `finishEnterTransition` в transition — удалён, официальный
  `onAnimationEnd` снимает флаг напрямую;
* источник текста — официальный `messageText` (не `pengramUnwrappedText()`);
* bail пустого поля ввода и кадровый лог `FIELD` в transition — удалены;
* `PengramSendTrace` в transition — удалён (трассировка осталась в ячейке,
  `ChatListItemAnimator`, `MessageObject`).

## Почему

Устройство (Xiaomi 2311DRK48G, Android 14) отклоняло каждую схему сессии:

| Сборка | Поведение на устройстве |
|---|---|
| run393 (прежняя схема, поле выключено) | пустой пузырь весь перелёт, текст «выскакивает» на конце |
| run399 (официальная пара, слой у поля) | обычная отправка нормально, crossfade-отправка без текста |
| run401 (пара, paint-альфа вместо слоя) | **мигание на каждом сообщении** |
| run397 (мастер, официальный код) | «текст отправляется нормально» — эталон |

Лог run401: обе отправки `crossfade=true spans=true`, `FIELD fade=255→0`,
строка `alpha 0→1`, кадры идут без пропусков — статически пара идеальна, но
на экране пользователь видит мигание. Механику мигания статически доказать
не удалось за три итерации; принято решение пользователя — вернуть код,
который он подтвердил.

## Что осталось в силе

* Гейт ячейки `setEnterTransitionInProgress` (линияж ветки) — не тронут:
  во время перелёта строку рисует overlay, ячейка глушится.
* Обход viewport-диапазона в `drawMessageText` (`drawAllBlocks` для
  overlay), поколенческая проверка в ячейке, watchdog'и ячейки — линияж,
  не менялся сессией.
* `MessageObject.pengramUnwrappedText()`, мягкая вёрстка, антикраш-фолбэк
  вёрстки — линияж; transition их больше не вызывает.
* Числовая модель в тестах (201 кадр, сумма альф пары ≥1) — официальная
  формула `alphaProgress` не менялась.

## Проверки

* `scripts/test-pengram-send-text-visible.py` — закрепляет откат: официальный
  жизненный цикл, `messageText` как источник, `saveLayerAlpha` у поля,
  отсутствие `drawFieldCopy` / paint-альфы / лога `FIELD` / `finishTransition`
  в transition; модель кадров остаётся.
* `scripts/test-pengram-send-text-draw.py` — пересылка и выбор диапазона

* `scripts/test-pengram-send-trace.py` — transition без трассировки
  (официально), трассировка остальных точек сохранена.
* `scripts/test-pengram-text-visibility.py`,
  `scripts/test-pengram-send-delete-regressions.py` — жизненный цикл
  откатан, линияж-часть (ячейка, контейнер, typing) не тронута.
* Локально: все сюиты `scripts/test-pengram-*.py` PASS, аудит пересобран.

## Чего этот документ не утверждает

Не проверяется на устройстве здесь (нет телефона/эмулятора). Критерий
приёмки — визуальное совпадение с мастер-сборкой run397: текст и время
строки видны с первого кадра перелёта на каждой отправке, в конце нет
«вспышки» и прыжка. Если откатированная версия на устройстве поведёт себя
иначе — это отдельный факт, фиксируемый логом (без `FIELD`: теги сессии в
transition больше не пишутся).
