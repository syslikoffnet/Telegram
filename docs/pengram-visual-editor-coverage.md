# Pengram visual editor: scope and safety checklist

This is an implementation inventory, **not a claim that the entire Telegram UI is reproduced**. The editor opens directly from Pengram settings and starts on a full-available-height sample chat list. It now uses Telegram's actual ActionBar, animated MainTabsLayout/GlassTabView, SettingsActivity.SettingCell, AvatarDrawable and sample-only ChatMessageCell preview, rather than stacking a second fake title bar over the editor. The chat preview fills its allotted screen height; placement mode retains the older drag schematic as a separate editing tool, not the default conversation view. Its editing sheet is hidden until a row is selected or the edit icon is pressed, rather than squeezing the preview into half the screen. Its synthetic names, texts, calls, story, cover, and search results are resource strings and local view state; it must never load dialogs, contacts, media or call history from an account. Visual edits are drafted in memory: **Save** commits supported settings shared by all accounts; leaving without Save discards them. Unrelated settings are not part of the draft.

## Interactive preview

| Surface | Interaction | Persisted changes |
| --- | --- | --- |
| Chat list | Open one of eight sample conversations; editable sample search (filters only synthetic chats); compose and story screens; long-press a row/avatar | MD3 dialogs, unread tone, dividers, avatar shape; title and font; story/compose visibility |
| Chat | Default view uses Telegram ChatMessageCell components with synthetic peers and a local composer. Tap a sample bubble/mark or the Pengram bar to inspect; use a separate placement mode to drag avatar/bar only to marked slots; sample input never sends to Telegram and survives editor view recreation. | Bubble radius/text size, group avatar placement, deleted mark, bar position/visibility, menu items |
| Menus | Long-press and drop an item onto another item or a section header; ghosted hidden items live in a separate editor-only section | Shared menu/chat-action order, hide/restore, permitted main/island placements; inspector arrows offer a non-drag reorder alternative |
| Settings | Native SettingCell rows for the ordinary visible categories; a separate "Arrange settings sections" screen exposes drag/drop and faded hidden rows. Other account categories show only static labels, never live account data. | Shared settings row order and hide/restore (Pengram entry may only be restored, not newly hidden here); native settings list labels are not editable |
| Tabs | Telegram's animated MainTabsLayout switches between sample chats, contacts, settings/calls and profile; the profile icon is a fake avatar, not the user's photo. Long-press to edit. | Global visibility of optional tabs; Chats stays present. Calls and Settings remain alternative views of the third slot depending on the active account. |
| Appearance | Inspect MD3 dialogs/search/FAB/settings/sheet/dialog samples; browse the generated list of Pengram sections and settings inside the same preview; select a row to see its actual breadcrumb and a contextual control where staging is supported | Existing Pengram MD3/Monet/font preferences, shared across accounts; list-only rows do not silently change preferences |
| Player | See a synthetic track/cover and switch style/background/cover shape | Existing player appearance preferences; no audio playback, no change to penguin options |
| Search/contacts/calls/profile | Navigate with synthetic results only | Only settings with an actual matching global appearance control are editable; no calls, messages or account changes |

Hidden items are intentionally shown faded **only in the editor**, in a separate section, so they can be restored. The chat list and dialogs are not reorderable: their real order is not an appearance preference. Required Chats navigation and the Pengram/Settings access points cannot be newly hidden in this editor. On Android 21–23 the item drag gesture uses `startDrag`; Android 24+ uses `startDragAndDrop`.

## Still not exact / verification pending

- The navigable settings inventory has 344 indexed rows (including radio options, labelled sliders, dedicated chat-avatar and profile-history controls). The editor now has an in-preview settings search using the same names, paths and colloquial synonyms as global Pengram search; full breadcrumbs are shown without truncation, results are loaded in batches of 60, and selection navigates to the appropriate section and highlights the row when it exists. It covers browsable **lists**, not 344 pixel-accurate, directly editable mock controls. Preview-backed MD3, avatar, title/custom title, all five deleted-mark modes, chat-menu placement, font, selected visibility and player options have inline contextual actions; unsupported rows explicitly say that they cannot be staged. Opening the real setting from the editor was removed because it would bypass Save. Static native account-category rows remain informational only. Hidden penguin controls are intentionally excluded: they remain accessible only through the secret 10 taps on the animated penguin.
- The default chat uses native ChatMessageCell components, but its draft bubble radius/text-size slider preview remains in the separate placement schematic until Save: ChatMessageCell reads Telegram's live global metrics, which must not be mutated during a draft. Native Telegram account screens, call screens, media viewers, and some other Pengram secondary screens are **not** pixel-accurate editable replicas. They should not be presented as such. Existing settings outside the visual editor remain available.
- A sample-data preview cannot demonstrate live audio/video, actual stories, real chat search or real account-specific state without breaking its isolation; these are intentionally inert.
- User reported real Xiaomi Android 14 crashes from `TextView.setText(int)` and `TextView.setHint(int)` with invalid string IDs. Build #229 guarded panel labels, and commit `500ff954` guards the search/composer/custom-title hints. Neither these guards nor the full-screen editor/draft changes have been validated on a device. Manual Android 21+/small-screen/large-font/dark-theme/drag-cancel/accessibility checks remain pending; CI compilation alone cannot prove runtime behavior.
- If the full literal scope means editing every Telegram screen and every Pengram preference in this single surface, that work remains open; prioritize real preference-backed controls and truthful synthetic previews rather than nonfunctional lookalikes.
